GitHub Gist 云端同步使用教程

🎯 这个功能能做什么？

把你的便签本、待办事项、密码库等所有数据自动备份到 GitHub 私有 Gist， 换设备（手机/电脑）打开同一个站点就能**一键恢复**，数据永远不丢。 全程零成本，纯 GitHub 官方服务。

📋 第一步：生成 GitHub Token（只需做一次）

  1. 打开 这个链接
  2. 如果 GitHub 显示 "Fine-grained token"，点上方 "Switch to classic token"
  3. 勾选 gist （仅此一项），描述随便写
  4. 滚动到底部点绿色按钮 "Generate token"
  5. 立即复制生成的 Token（只显示一次，刷新就没了）

🔑 第二步：在 StreePortal 中连接

  1. 把复制的 Token 粘贴到上方 "Personal Access Token" 输入框
  2. "Gist ID" 留空 → 点 "连接 / 创建"
  3. 等待几秒钟，看到绿色 "已连接" 徽章就成功了！
  4. 系统会自动创建一个私有 Gist 来存数据，别人看不到

💾 第三步：日常使用

  • 导航栏那个 云朵图标 = 一键上传当前数据
  • 勾选 "自动同步" + 选择频率，站点会定期自动备份
  • 换设备时：粘贴同样的 Token + Gist ID → 点 "从云端拉取"
  • Gist ID 在连接成功后会自动填入，也可以在 GitHub 的 Gist 首页 找到

安全小贴士

  • • Token 只保存在你本地浏览器，不会发送到任何其他服务器
  • • 只给了 gist 一个权限，即使泄露也只能读写你的 Gist，拿不到代码或仓库
  • • 想停用？去 GitHub Settings → Developer settings → Personal access tokens 里点删除即可
